# 다음 Codex 세션 지시문

첨부 ARMORY 대시보드 프로젝트를 인수하여 이어서 작업해줘.

1. README.md를 읽고 dist/index.html, dist/app.js 및 원본 CSV의 구조를 파악해.
2. 현재 실제 데이터와 집계 정의를 유지해. 예시 데이터를 추가하거나 없는 값을 0으로 대체하지 마.
3. 기존 구조는 빌드 없는 순수 HTML/CSS/JavaScript야. 별도 요청 없이 프레임워크나 서버로 이전하지 마.
4. `node tests/verify.cjs`로 검증하고, 사용 가능한 브라우저 환경에서 실제 화면과 상호작용을 점검해. 기존 검증은 DOM 대역 기반이며 시각 검수는 안 된 상태야.
5. 사격 테스트, 총기·모듈 코드는 현재 CSV에 없어. 새 데이터나 명시적 수집 규격을 받기 전에는 분석 결과를 꾸며내지 마.
6. 소스 파악 후 기능, 실행 방법, 확인된 문제를 간단히 보고해. 이후 내가 요청하는 수정사항을 적용해.
7. 기존 Sites를 수정할 경우 README의 project_id를 재사용하고 최신 원격 소스를 확인해. 로컬 작업을 인수하는 것만으로 사이트 공개 범위를 바꾸지 마.

우선 프로젝트 인수와 실행·검증을 진행해줘.
