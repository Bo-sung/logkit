# ARMORY 대시보드 인계

## 실행
`dist/index.html`을 브라우저에서 열면 됩니다. 빌드·설치·서버·API 키가 필요 없는 HTML/CSS/JavaScript 프로젝트입니다.
필요하면 프로젝트 루트에서 `python -m http.server 8080 --directory dist` 후 http://localhost:8080 접속.

## 구성
- dist/index.html: 레이아웃, 스타일
- dist/app.js: CSV 파싱, 집계, 화면, 리플레이
- dist/data.js: 기본 실제 데이터 (window.INITIAL_LOGS) — 저장소 미포함
- data/7f18f899_20261015_102421.csv: 원본 CSV — 저장소 미포함
- tests/verify.cjs: Node.js 기반 로직 검증. `node tests/verify.cjs`
- CODEX_HANDOFF.md: 다음 Codex 세션 지시문

## 현재 상태
원본 4,196행. 판매 9건, 판매액 29,155. 플레이어 상태 1,737개, 블록 파괴 2,411건. 완결된 작업대 진입/퇴장 9쌍. 습격 1회는 게임 시간 34.756916초에 사망 종료.
CSV 원본 열: timestamp_utc, level, category, scene, message, data_json, stack_trace.

## 기능
개요 / 상점 / 습격 / 총기·모듈 / 이벤트 탐색기 / 수집 정의.
씬 필터, KST·UTC 전환, 검색·페이지 이동·JSON 상세, 필터된 CSV 내보내기.
실측 XZ 경로·카메라 Y 방향 재생, 재생 속도, 체력·상자·적 수 계단 그래프.
같은 형식의 CSV 불러오기. 브라우저 메모리에서만 사용하며 새로고침하면 기본 데이터로 복귀.

## 집계 규칙
- Shop / 총 판매만 매출 합산. Unity 콘솔 판매 출력 중복 제외.
- satisfied는 판매 조건 만족. 전체 주문 성공률이 아님.
- 작업대 체류는 같은 씬의 시간순 진입→퇴장. 주문 ID가 없으므로 주문별 연결 금지.
- timestamp_utc는 UTC, data_json.time은 게임 시간. 시간축 혼합 금지.
- 직전 상태 샘플 유지. 마지막 샘플 체력 1이지만 종료 이벤트 체력 0 반영.
- 모듈/재료 상자는 별도 표시. 금고로 임의 명칭 변경 금지.
- 지도는 실측 좌표만 표시. 구조물 데이터 없음. 블록 ID로 위치 추정 금지.
- 총기 코드, 휴대 모듈, 사격 테스트 및 사격 인풋은 현재 미수집.
- 종료 보상은 기록값. 사망 후 실제 지급 여부 확인 불가.

## 검증과 한계
JavaScript 구문, 6개 화면 생성, 원본 CSV 파싱 일치, 집계 수치, 씬 필터, 검색, 사망 종료 체력 검증 통과.
DOM 대역을 사용하는 로직 검사이며 실제 브라우저 시각/클릭 검수는 미실시. 다음 세션에서 실제 브라우저로 확인할 것.
대용량 파일, 다양한 게임 버전의 스키마, 다중 습격 파일은 추가 검증 필요. 현재 집계는 명시한 이벤트명 기준.
실제 플레이 로그가 포함되므로 공개 배포 시 데이터 포함 여부를 사용자 의도에 맞춰 확인.

## 실제 데이터 (저장소 미포함)
logkit은 공개 저장소이므로 실제 플레이 로그(`data/*.csv`, `dist/data.js`)는 `.gitignore`로 제외했다.
화면 실행과 `node tests/verify.cjs`는 두 파일이 있어야 동작하므로, 인계 ZIP(ARMORY_Codex_Handoff.zip)에서 같은 경로에 복사해 둔다.

## 기존 Sites 참조
기존 비공개 배포 사이트의 URL·project_id·배포 커밋은 인계 ZIP의 원본 README에만 둔다(공개 저장소에 올리지 않음).
기존 사이트를 수정한다면 Sites 도구로 그 ID의 최신 소스와 권한을 먼저 확인하고 같은 ID를 재사용. 이 스냅샷 이후의 원격 변경을 덮어쓰지 말 것.
